### Fixes found by the real runs

- **97d55f1, the 4-minute search (F3) had a second cause.** The plugin's slash command `commands/setup-project.md` and the skill share the name `setup-project`. Invoking it returned the command's one line ("Invoke the setup-project skill and follow it in full"), so the model never saw the skill text and searched the disk for it, within 5 s of starting. Two chain starts were stopped for this (`logs/v07-chain-aborted.stream.jsonl`, `v07-chain-aborted2.stream.jsonl`). The command now names the skill file by path. The third start read the skill at +3 s and never searched.
- **4c923fd, "synchronous" has to be written out.** The template said "one Agent call, no `run_in_background`". In the first build run the orchestrator left the field out and Claude Code answered "Async agent launched": U0 ran in the background. Every setup-chain dispatch wrote `run_in_background: false` and came back synchronously. The template and KD-020 now say to write `run_in_background: false`, and what to do if a call still comes back as launched.

## Not done, and why

- **Real CLAUDE.md files can still pass 50 lines.** The limit holds for the templates; a project's invariants block is copied in full and is most of the file (Dues: 66 lines). Shortening project rules automatically risks dropping one; the doctor flags it MAJOR and the user decides.
- **plan-lint still takes three rounds** (1,390 s, the only step slower than v0.6.1). The spec did not cover it; the findings were real (type mismatches between the design and the plan), so cutting rounds would hide defects.
- **The generated `db-migration-review` checklist contradicts some designs** (asks for down migrations, tenancy and soft delete). Found by the v0.7 doctor; not part of the spec; left for a later version.
- **The chain makes no commits.** By design: the skill leaves the first commit to the user, and the seeded `PROGRESS.md` tells the orchestrator to make it before U0 if it is missing.
- The minor audit findings outside the spec (F10, F13 to F16) were not touched.
- The U0 brief was 7 characters over the 6,000-char budget. Not worth a change.
- In build run 1 the orchestrator also started a shell watcher that raised a false "stalled" alert (its time check was broken), then fixed it itself. Run 2 did not need one. Not changed.
